  - What is missing that would let Lisp and its development and
    deployment platforms reclaim such glory?

    - What features that no current production system has?
  - What would fulfil the /spirit of lisp/ even if many or most Lisp
    programmers considered that it was no longer a Lisp?
    - Especially by being true to the R5RS inspiring introduction!
